Featured Security tooling

RepoGuard

Problem. People install GitHub repositories and AI skills without knowing if they hide malware or leaked secrets.

A pre-install scanner that fetches a public GitHub repo at an exact commit and statically analyzes it. Target code is never installed, imported, or executed. The only verdicts are APPROVED or REJECTED, with per-file findings. Secrets are redacted before they are stored in reports.

Featured Civic web platform

Barangay SAGIP

Problem. Barangay offices still handle assistance and emergencies without consistent classification or responder assignment.

A Laravel platform for resident assistance requests, maps, notifications, dashboards, and reports. A private FastAPI service classifies request type and urgency with tokenization and curated rules — not machine learning — then scores nearby responders. Ambiguous or low-confidence cases go to human review.

Eye-gaze AAC

Problem. Some deaf users can communicate only with their eyes, and dedicated eye trackers are expensive.

A research prototype that uses a webcam so a person can select phrases by looking, then show captions and speak them aloud. Private thesis work — no public repository.
