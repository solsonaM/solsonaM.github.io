Featured Security

RepoGuard

Problem: People install GitHub repos and AI skills without knowing if they hide malware or leaked secrets.

Fetches a public repository at an exact commit and statically scans it. Target code is never installed, imported, or executed. Verdict is only APPROVED or REJECTED, with per-file findings. Secrets are redacted in reports.

Featured Civic / Web

Barangay SAGIP

Problem: Barangay offices still handle assistance and emergencies without consistent classification or responder assignment.

Residents submit requests; a rule-based tokenizer classifies type and urgency, scores nearby responders, and escalates ambiguous cases for human review. Includes maps, personnel, notifications, dashboards, and reports.

Private · Research Accessibility

Eye-gaze AAC

Problem: Some deaf users can communicate only with their eyes, and dedicated eye trackers are expensive.

A research prototype that uses a webcam so a person can select phrases by looking, then show captions and speak them aloud. Thesis work on making gaze-based selection more reliable.
